Live rejudging invokes the blind model again, so score changes contain both
policy changes and model sampling variance. The original traces retain the raw
model JSON before deterministic caps. Reapplying the calibrated deterministic
policy to those same raw judgments isolates the rule change:

| Condition | Original stored Task | Original raw-model Task | Calibrated-policy replay Task | Live rejudge Task |
| --- | ---: | ---: | ---: | ---: |

| Product `baseline` | 0.6720 | 0.9229 | 0.9229 | 0.9258 |
| Product `shape-product-spec-enabled` | 0.8787 | 0.9727 | 0.9727 | 0.9567 |

The Data baseline raw-model score is reduced from 0.9333 to 0.9000 by the still
valid structured-ledger cap. Its fan-out and independent-verification scores
remain 1.0. The calibrated paired Task delta is therefore exactly +0.1000 under
both deterministic replay and live rejudging.

The Product-spec term misses no longer alter scores. Using the original model
outputs, the calibrated Task delta is +0.0498; the live rejudge produced +0.0309.
That difference is model sampling variance. Both views show a modest improvement
in flow/state completeness and observable acceptance criteria, not the previous
+0.2067 effect suggested by literal-term caps.

## Calibration Assertions

### Route Confounding

`run-summary.json` now stores both score types and both paired deltas. The three
baseline controls still fail the critical route criterion by design, but this no
longer creates a hidden +0.10 treatment advantage in the quality comparison.

### Data Fan-out

The baseline artifact audit now recognizes the substantive explanation without
requiring the word "fan-out": unique `order_id` grain, a direct join expanding
three paid orders to five rows, and the incorrect 720.00 sum. `fanout-control`
and `independent-verification` both score 1.0. The invalid ledger remains capped
at 0.4, preserving the real contract distinction.

### Product Semantics

Literal term misses remain visible in `artifact-audit.json` but are no longer
vetoes. The baseline now passes target options, flows/states, and scope/open
policy on semantic evidence. Its actual gaps remain visible: no finance-queue
empty state and some implementation-oriented acceptance criteria. The enabled
spec's measurable advantage is concentrated in those areas.

### Presentation Placeholder

The baseline gate now reports `placeholder_hits=[]`. It still fails the technical
gate for three 7-point numeric badges (`01`, `02`, `03`), so rendered verification
remains 0.72. This proves the placeholder false positive was removed without
silently converting a separate tiny-text warning into a pass.
