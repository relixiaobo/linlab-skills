# Modern Swiss

Use for product, transformation, operating models, conference talks, and short live presentations.

## Character

- Hard grid, decisive type, high whitespace contrast, and a small number of saturated signals.
- White and black dominate; red communicates the primary move, cyan a second state, and yellow only a warning.
- Layouts may be asymmetrical but alignment must be exact.

## Signature Moves

- Use a large numeric or typographic anchor aligned to the same modular grid across sections.
- Turn process changes into visible state changes rather than a row of identical cards.
- Use full-bleed real product or interface evidence only when the audience needs to inspect it.

## Adaptation

The grid is a prior, not the concept. Replace generic blocks with a content-specific signal path, state machine, launch sequence, or operating loop. Give CJK headlines additional width and avoid forced single-line treatment.
