# Dark Technology

Use for AI, developer tools, data products, cybersecurity, technical launches,
and demos where a dark interface-native environment supports the subject.

## Character

- Neutral near-black canvas, cyan signal, violet secondary state, and precise
  hairline structure.
- Clean sans-serif type with monospace used selectively for code, labels, and
  measured states.
- Diagrams, traces, and real interfaces provide the visual interest; glow is
  restrained and never substitutes for hierarchy.

## Signature Moves

- Use one active signal path or state transition across the deck.
- Pair interface evidence with a concise mechanism or performance explanation.
- Reserve luminous accents for active nodes, selected series, and verified
  values.

## Adaptation

Derive the recurring geometry from the real system: request path, model stack,
security boundary, agent loop, or data flow. Avoid generic circuit decoration
and do not use this theme merely because the topic mentions AI.
