# Technical Blueprint

Use for engineering, architecture, energy, operations, and technical due diligence.

## Character

- Precise system diagrams, explicit scale and scope, and visible separation between observed facts and engineering interpretation.
- Pale technical fields and graphite anchors; cyan marks system flow, yellow marks interfaces, and red marks risk or failure.
- Construction lines are functional. Avoid decorative grid overlays that do not carry meaning.

## Signature Moves

- Use one sectional or systems view as the deck's recurring explanatory device.
- Show interfaces, dependencies, and constraints with SVG connectors and explicit labels.
- Pair the system view with a compact decision or risk register rather than a second decorative diagram.

## Adaptation

Derive the visual grammar from the real system: subsurface-to-surface, component architecture, process flow, network topology, or control loop. Use SVG paths for arrows and never CSS border triangles.
